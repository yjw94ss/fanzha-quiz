# 反诈宣传有奖答题

单文件 HTML 反诈知识答题页，**零外部依赖、离线可用**，双击即可在任何现代浏览器（含 Win10 Edge / Chrome）中运行。

- 50 道单项选择题，每题 2 分，满分 100 分
- 答一题立即判对错，并显示正确答案与解析（答后锁定）
- 实时得分、答题卡跳题、逐题解析、错题筛选
- 键盘快捷键：`1 2 3 4`（或 `A B C D`）选择选项，`空格` 下一题，`← →` 翻题；鼠标点击同样可用

线上地址：https://yjw94ss.github.io/fanzha-quiz/

## 更新线上页面

`index.html` 为发布文件。本地修改后执行：

```bash
cp 反诈有奖答题.html index.html   # 若本地也维护了同名源文件
git add -A && git commit -m "更新题库" && git push
```

推送后 GitHub Pages 约 30 秒内自动生效。
